# The Corridor

A short interactive leadership story for senior roles in Peru's mining sector, covering the **Corporate Affairs & Social License** domain. Candidates play through 13 decisions as a mine's VP of Corporate Affairs during a month-long road-blockade crisis.

- Rule-based scoring, no AI: fixed options, competency points and target profiles.
- Animated SVG scenes, narrated lines (browser text-to-speech) and word-by-word subtitles.
- Results show a candidate style profile and a recruiter report: match %, competencies vs. target, interview probe flags and a decision log.

## Run it

It's a single self-contained file. Open `index.html` in a browser, or host it with GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.

## Status

Prototype v0.2. Scores are not calibrated yet, and results aren't stored anywhere; each player sees them only on their own screen.
